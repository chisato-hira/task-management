# 要件定義書：タスク管理アプリ（Trello風）

## 1. プロジェクト概要

### 1.1 背景

本プロジェクトはプログラミングスクールの課題として実施する。
Web アプリケーション開発の一連の工程（要件定義・設計・実装・テスト）を実践し、フロントエンド・バックエンド・データベースを含む総合的なアプリケーション開発スキルを習得することを目的とする。

### 1.2 目的

Trello 風のカンバンボード形式によるタスク管理 Web アプリケーションを開発する。
タスクの状態を視覚的に管理でき、データベースによるデータ永続化を行う。

### 1.3 利用者

- 個人利用（1人・認証なし）

### 1.4 利用環境

- Web ブラウザ（PC）

---

## 2. 機能要件（概要）

ボード表示・タスクの CRUD・ドラッグ＆ドロップ移動・データ永続化の機能を提供する。

詳細は [機能要件定義書](functional-requirements.md) を参照。

---

## 3. 非機能要件

### 3.1 対応ブラウザ

| ブラウザ | バージョン |
|---------|-----------|
| Google Chrome | 最新版 |
| Microsoft Edge | 最新版 |

- 上記以外のブラウザ（Safari、Firefox 等）は動作保証対象外とする

### 3.2 性能要件

- 画面の初期表示：3秒以内
- タスクの作成・編集・削除操作：1秒以内にレスポンスを返す
- 想定タスク数：最大 100 件程度

### 3.3 レスポンシブ対応

- PC（横幅 1024px 以上）のみを対象とする
- タブレット・スマートフォンは対象外

### 3.4 セキュリティ

- 認証機能は設けない（個人利用のため）
- SQL インジェクション・XSS 等の基本的な脆弱性対策は実施する

---

## 4. 画面設計（概要）

ボード画面・タスク作成/編集モーダル・削除確認ダイアログの 3 画面で構成する。

詳細は [画面設計書](screen-design.md) を参照。

---

## 5. データベース設計（概要）

tasks テーブル 1 つで構成し、タスクのタイトル・説明文・優先度・期限・ステータスを管理する。

詳細は [データベース設計書](database-design.md) を参照。

---

## 6. 技術スタック（概要）

フロントエンドに React + TypeScript、バックエンドに Java / Spring Boot、データベースに PostgreSQL を使用する。

詳細は [技術スタック](tech-stack.md) を参照。
