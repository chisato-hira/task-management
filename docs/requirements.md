# タスク管理アプリ 要件定義書

## 1. プロジェクト概要

個人で使えるTrello風のタスク管理アプリ。
カンバンボード形式でタスクを視覚的に管理できる。
スクールの課題として作成する。

---

## 2. ターゲットユーザー

- 自分自身（個人利用）

---

## 3. 機能要件

### カラム（列）

- 3つのカラムを表示する
  - `未着手` / `進行中` / `完了`
- カラムの順番は固定

### カード（タスク）

- カードの追加ができる
- カードの削除ができる
- カードを編集できる（タイトル・説明文・期限）
- カードをドラッグ&ドロップで別のカラムに移動できる
- カードをクリックすると詳細モーダルが開く

### カードに持つ情報

| 項目 | 必須 | 表示場所 |
|------|------|---------|
| タイトル | 必須 | カード一覧・詳細 |
| 説明文 | 任意 | 詳細のみ |
| 優先度（高・中・低） | 任意 | カード一覧・詳細 |
| 期限（日付） | 任意 | カード一覧・詳細 |

### データの保存

- ブラウザを閉じてもデータが消えないようにする
- ブラウザの `localStorage` に保存する

---

## 4. 非機能要件

- シンプルで直感的に使えること
- スマートフォンは対象外（PC画面のみ）
- 対応ブラウザ：Google Chrome の最新版を対象とする

---

## 5. 画面一覧

| 画面名 | 説明 |
|--------|------|
| ボード画面 | カラムとカードを一覧表示するメイン画面 |
| カード詳細モーダル | カードをクリックしたときに開く。タイトル・説明文・期限の表示と編集が両方できる。編集後は保存ボタンで反映する。 |

---

## 6. 技術構成

| 役割 | 使用技術 |
|------|---------|
| フレームワーク | React + TypeScript |
| ビルドツール | Vite |
| スタイリング | Tailwind CSS |
| ドラッグ&ドロップ | @dnd-kit/core |
| データ保存 | localStorage |
