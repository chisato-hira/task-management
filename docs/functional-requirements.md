# 機能要件定義書

## 1. 機能一覧

| No | 機能名 | 概要 |
|----|--------|------|
| 1 | ボード表示機能 | カンバンボード形式で画面を表示する |
| 2 | タスク作成機能 | タスクを新規作成する |
| 3 | タスク編集機能 | 作成済みタスクを編集する |
| 4 | タスク削除機能 | 不要なタスクを削除する |
| 5 | タスク移動機能 | ドラッグ＆ドロップでタスクを別カラムに移動する |
| 6 | データ保存機能 | API経由でデータベースにデータを永続化する |

---

## 2. 機能詳細

### 2.1 ボード表示機能

- カンバンボード形式で画面を表示する
- 以下の3つのカラム（列）を固定で表示する
  - 未着手
  - 進行中
  - 完了

### 2.2 タスク作成機能

- 以下の情報を入力してタスクを作成できる
  - タイトル（必須）
  - 説明文（任意）
  - 優先度（高・中・低）（任意）
  - 期限（日付）（任意）
- タイトルが未入力の場合、エラーメッセージを表示して保存しない

### 2.3 タスク編集機能

- 作成済みタスクの各項目を編集できる
  - タイトル
  - 説明文
  - 優先度
  - 期限
- タイトルが未入力の場合、エラーメッセージを表示して保存しない

### 2.4 タスク削除機能

- 不要なタスクを削除できる
- 削除前に確認ダイアログを表示する

### 2.5 タスク移動機能

- ドラッグ＆ドロップでタスクを別のカラムに移動できる
- 移動するとステータスが自動的に更新される

### 2.6 データ保存機能

- タスクのデータはAPI経由でデータベースに保存する
- ブラウザを閉じてもデータが消えないようにする
- localStorageは使用しない

## 3. バリデーション一覧

| フィールド | 必須 / 任意 | ルール |
|-----------|------------|--------|
| タイトル | 必須 | 空欄不可・255文字以内 |
| 説明文 | 任意 | 制限なし |
| 優先度 | 任意 | `HIGH` / `MEDIUM` / `LOW` のいずれか |
| 期限 | 任意 | 日付形式（YYYY-MM-DD） |
| ステータス | 必須 | `TODO` / `IN_PROGRESS` / `DONE` のいずれか |

※ タイトルが空欄の状態で「追加」または「保存」を押した場合、エラーメッセージを表示して保存しない。

## 4. ユースケース

アクター：利用者（自分自身）

| ユースケース | 操作の流れ |
|-------------|-----------|
| タスクを追加する | ① 「＋ カード追加」をクリック → ② モーダルに入力 → ③「追加」ボタンを押す → ④ カードが一覧に表示される |
| タスクを確認する | ① カードをクリック → ② 詳細モーダルで内容を確認する |
| タスクを編集する | ① カードをクリック → ② 詳細モーダルで内容を変更 → ③「保存」ボタンを押す → ④ 更新内容が反映される |
| タスクを削除する | ① カードをクリック → ② 「削除」ボタンを押す → ③ 確認ダイアログが表示される → ④「はい」を押す → ⑤ カードが一覧から消える |
| タスクを移動する | ① カードをドラッグ → ② 別のカラムにドロップ → ③ ステータスが自動更新される |
