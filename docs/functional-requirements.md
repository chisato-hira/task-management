# 機能要件定義書

## 1. 機能一覧

| No | 機能名 | 概要 |
|----|--------|------|
| 1 | ボード表示機能 | カンバンボード形式で画面を表示する |
| 2 | タスク作成機能 | タスクを新規作成する |
| 3 | タスク編集機能 | 作成済みタスクを編集する |
| 4 | タスク削除機能 | 不要なタスクを削除する |
| 5 | タスク移動機能 | ドラッグ＆ドロップでタスクをカラム間・カラム内で移動する |
| 6 | データ保存機能 | API経由でデータベースにデータを永続化する |
| 7 | 並び替え機能 | カラムごとにタスクの表示順を切り替える |
| 8 | 完了タスク一括削除機能 | 完了カラムのタスクをまとめて削除する |

---

## 2. 機能詳細

### 2.1 ボード表示機能

- カンバンボード形式で画面を表示する
- 以下の3つのカラム（列）を固定で表示する
  - 未着手
  - 進行中
  - 完了
- カラムが空の場合「タスクがありません」と表示する

### 2.2 タスク作成機能

- 「＋ タスク追加」ボタンは未着手カラムにのみ表示する
- 以下の情報を入力してタスクを作成できる
  - タイトル（必須）
  - 説明文（任意）
  - 優先度（高・中・低）（任意）
  - 期限（日付）（任意）
- タイトルが未入力の場合、エラーメッセージを表示して保存しない

### 2.3 タスク編集機能

- 作成済みタスクの各項目を編集できる
  - タイトル
  - 説明文
  - 優先度
  - 期限
- タイトルが未入力の場合、エラーメッセージを表示して保存しない

### 2.4 タスク削除機能

- 不要なタスクを削除できる
- 削除前に確認ダイアログを表示する

### 2.5 タスク移動機能

- ドラッグ＆ドロップでタスクを別のカラムに移動できる
- 移動するとステータスが自動的に更新される
- 同じカラム内でもドラッグ＆ドロップで順番を変更できる（「登録順」選択時のみ）

### 2.6 データ保存機能

- タスクのデータはAPI経由でデータベースに保存する
- ブラウザを閉じてもデータが消えないようにする
- localStorageは使用しない

### 2.7 並び替え機能

- カラムごとに個別で並び替え順を選択できる
- 以下の3種類の並び順を切り替えられる
  - 登録順（デフォルト）
  - 優先度順（高 → 中 → 低）
  - 期限順（期限が近い順・期限なしは最後）
- 「登録順」選択中はドラッグ＆ドロップで自由に並び替えができる
- 「優先度順」「期限順」選択中はボタン押下時に自動でソートされる
  - 異なる優先度／異なる期限のタスクを跨ぐドラッグ＆ドロップによる並び替えは無効になる
  - 同一優先度／同一期限のタスク同士であれば、同一カラム内でのドラッグ＆ドロップによる並び替えが可能
- 「優先度順」「期限順」選択中でも、カラム間のドラッグ＆ドロップ（タスクの移動）は有効

### 2.8 完了タスク一括削除機能

- 完了カラムに「全削除」ボタンを表示する
- ボタン押下時に件数を表示した確認ダイアログを表示する
- 確認後、完了カラムのタスクをすべて削除する

## 3. バリデーション一覧

| フィールド | 必須 / 任意 | ルール |
|-----------|------------|--------|
| タイトル | 必須 | 空欄不可・255文字以内 |
| 説明文 | 任意 | 制限なし |
| 優先度 | 任意 | `HIGH` / `MEDIUM` / `LOW` のいずれか |
| 期限 | 任意 | 日付形式（YYYY-MM-DD） |
| ステータス | 必須 | `TODO` / `IN_PROGRESS` / `DONE` のいずれか |

※ タイトルが空欄の状態で「追加」または「保存」を押した場合、エラーメッセージを表示して保存しない。

## 4. ユースケース

アクター：利用者（自分自身）

| ユースケース | 操作の流れ |
|-------------|-----------|
| タスクを追加する | ① 未着手カラムの「＋ タスク追加」をクリック → ② モーダルに入力 → ③「追加」ボタンを押す → ④ タスクが一覧に表示される |
| タスクを確認する | ① タスクをクリック → ② 詳細モーダルで内容を確認する |
| タスクを編集する | ① タスクをクリック → ② 詳細モーダルで内容を変更 → ③「保存」ボタンを押す → ④ 更新内容が反映される |
| タスクを削除する | ① タスクをクリック → ② 「削除」ボタンを押す → ③ 確認ダイアログが表示される → ④「はい」を押す → ⑤ タスクが一覧から消える |
| タスクをカラム間で移動する | ① タスクをドラッグ → ② 別のカラムにドロップ → ③ ステータスが自動更新される |
| タスクをカラム内で並び替える | ① カラムが「登録順」の状態でタスクをドラッグ → ② 同じカラム内の別の位置にドロップ → ③ 表示順が変わる |
| 並び替え順を変更する | ① カラムの並び替えボタン（登録順・優先度順・期限順）をクリック → ② そのカラムの表示順が切り替わる（優先度順・期限順の場合は自動ソートされ、ドラッグによる並び替えは無効になる） |
| 完了タスクを一括削除する | ① 完了カラムの「全削除」ボタンを押す → ② 件数確認ダイアログが表示される → ③「はい」を押す → ④ 完了タスクがすべて削除される |
