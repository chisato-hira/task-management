## PR作成前チェックリスト

PR を作成する前に、以下の項目をすべて確認してユーザーに提示すること。

---

## ステップ1：チェックリストの確認

以下を順番に確認する：

### コード品質
- [ ] 削除したコードや不要なコードが残っていないか
- [ ] デバッグ用の `console.log` やコメントアウトが残っていないか
- [ ] TypeScript・Java のビルドエラーが出ていないか

### 動作確認
- [ ] ローカルで動作確認済みか

動作確認の起動手順：

```bash
# DB起動
docker compose up -d

# バックエンド起動
cd backend
./gradlew bootRun

# フロントエンド起動（別ターミナル）
cd frontend
npm run dev
```

ブラウザで確認： `http://localhost:5173`

---

## ステップ2：ユーザーへの提示

以下の形式でユーザーに提示し、確認を取ること：

```
以下の内容でPRを作成します。よろしいですか？

■ PRタイトル
[種別] 内容 (#Issue番号)

■ 関連Issue
Closes #XX

■ 変更内容
- （変更点を箇条書き）

■ チェックリスト確認結果
- 不要なコードの混入：なし
- ビルドエラー：なし
- 動作確認：済み

■ 確認手順
1. docker compose up -d
2. cd backend && ./gradlew bootRun
3. cd frontend && npm run dev
4. http://localhost:5173 をブラウザで開く
```

---

## ステップ3：確認後にPR作成

ユーザーから OK をもらってから `gh pr create` を実行する。
確認なしに自動実行してはいけない。
